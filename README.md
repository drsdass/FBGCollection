# Healthcare Pickup App MVP

A Flask-based specimen pickup dispatch app for healthcare / laboratory workflows.

## Features
- Nurse login
- Driver login
- Admin login
- Create pickup requests
- Driver accepts pickup
- Driver updates status
- Admin dashboard
- Email notification hooks
